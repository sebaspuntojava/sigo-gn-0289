## Práctica 01

Preparación del entorno de desarrollo y creación del proyecto base con React y Vite.

## Tecnologías

Node.js, npm, React, Vite, ESLint, Visual Studio Code y Git.

## Instrucciones de ejecución

### Requisitos

Instalar Node.js 24 LTS con npm, Git y Visual Studio Code.

En VS Code, instalar las extensiones ES7+ React/Redux/React-Native snippets, Prettier - Code formatter y ESLint.

### Instalar dependencias

Abre una terminal dentro de la carpeta del proyecto y ejecuta:

```bash
npm install
```

### Iniciar la aplicación

```bash
npm run dev
```

Abre la dirección que indique la terminal, normalmente [http://localhost:5173/](http://localhost:5173/).

La pantalla inicial de Vite y React incluye un contador que aumenta al hacer clic.

Para detener el servidor, presiona `Ctrl + C` en la terminal.

### Revisar el código y compilar

```bash
npm run lint
npm run build
```
